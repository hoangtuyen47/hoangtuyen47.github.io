## 🛠️ HƯỚNG DẪN QUẢN TRỊ & SOẠN THẢO BÀI HỌC TRỰC TIẾP TRÊN WEB

1. Trên website, Thầy bấm nút **"Bảng Quản Trị: Thêm Công Cụ & Lớp Học"** ở cuối cột bên trái (hoặc chữ "Khu vực Quản trị" ở chân trang).
2. Nhập mã PIN Quản Trị: Mặc định là **`admin123`** (hoặc mật khẩu mới nếu Thầy đã đổi).
3. Các chức năng trong Bảng Quản Trị:
   - **+ Thêm Công Cụ**: Nhập tên, ảnh, tính năng gạch đầu dòng, link trải nghiệm, link đăng ký.
   - **+ Thêm Lớp Học**: Nhập tên khóa, đối tượng, lịch học, link đăng ký.
   - **+ Thêm Học Liệu**: Soạn thảo bài học với đầy đủ:
     - Tên bài học & Module phân loại
     - Ảnh minh họa
     - Giới thiệu ngắn ngoài trang chủ
     - Nội dung văn bản chi tiết (Lý thuyết & Các bước thực hành)
     - Link Video YouTube bài giảng
     - Link sơ đồ 2D hoặc Link mô phỏng 3D
     - Hướng dẫn nối chân linh kiện
     - Mã nguồn Code mẫu
     - Link tài liệu PDF xem trực tiếp
   - **🔒 Đổi Mật Khẩu Admin**: Đổi mã PIN bảo mật cho hệ thống.
4. Bấm nút **"Lưu & Hiển thị thử"**: Dữ liệu sẽ cập nhật ngay trên trình duyệt để Thầy trải nghiệm.
5. Thầy bấm nút màu xanh **"📥 Xuất file data.js Cập Nhật"**: Trình duyệt sẽ tải về file `data.js`. Thầy chỉ cần kéo file `data.js` này thả vào GitHub repository `hoangtuyen47/vuivui` là toàn bộ người xem trên toàn thế giới sẽ thấy nội dung mới vĩnh viễn!
